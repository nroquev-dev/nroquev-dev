## 👋 ¿Quién soy?

Soy **Tamii**, desarrollador Full Stack. Me especializo en construir interfaces modernas y responsive con **React**, **Next.js** y **TypeScript**, cuidando tanto el código como la experiencia de usuario.

Me gusta trabajar con arquitecturas modulares, estado bien organizado y componentes reutilizables. Cada proyecto lo trato como una oportunidad para aprender algo nuevo y dejarlo mejor de como lo encontré.

```yaml
ahora:
  - 🔭 Construyendo productos web con Next.js
  - 🌱 Aprendiendo: TypeScript avanzado y buenas prácticas de arquitectura
  - 💬 Pregúntame sobre: React, Next.js, Tailwind CSS o Zustand
  - ⚡ Dato curioso: me obsesionan las interfaces limpias
```
